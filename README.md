\# U.S. States Game



U.S. states guessing game implementation using Python and Turtle graphics.



\## Features



\* Interactive map of the United States

\* Guess state names

\* Correct answers are displayed on the map

\* Tracks score

\* Generates a list of states to learn



\## Technologies



\* Python

\* Turtle

\* Pandas



\## How to run



pip install pandas

python main.py
